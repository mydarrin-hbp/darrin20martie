# My Darrin Home Page Mockup Brief

## Goal

Etapa 1 livreaza un mockup aprobat pentru `Home Page`, care va deveni baza pentru implementarea productiei in `My Darrin`.

## Main objective

Sa construim un homepage care:

- prezinta `My Darrin` ca platforma principala
- mentine `Home Best Pal` ca slogan
- comunica servicii + AI + parteneri + investitori
- poate fi implementat direct in proiectul existent fara redesign major ulterior

## Page objectives

- cresterea increderii in brand
- trimitere rapida catre servicii
- trimitere rapida catre `Devino partener`
- trimitere rapida catre `Devino investitor`
- introducere clara pentru `Darrin AI`
- pregatirea unui design-system reutilizabil

## Homepage content blocks

1. Utility bar
2. Header
3. Hero
4. How it works
5. Featured services
6. Darrin AI
7. Partner CTA
8. Investor CTA
9. Trust / compliance / company data
10. Footer

## Mandatory visual rules

- Platform colors: `#EF7F1A`, `#1E2E4D`
- AI colors: `#09A299`, `#117A73`
- `My Darrin` trebuie sa fie dominant vizual fata de mostenirea HBP
- robotul Darrin poate ramane asset-cheie, dar folosit mai matur, mai premium si mai product-oriented
- designul trebuie sa para modern, curat si scalabil, nu template generic

## Suggested homepage message direction

### Hero headline examples

- `My Darrin connects services, people and AI for smarter home operations.`
- `Servicii pentru casa, coordonare inteligenta si executie reala, intr-o singura platforma.`
- `My Darrin transforma cererea de servicii in executie rapida, asistata de Darrin AI.`

### Supporting message

- platforma unifica servicii, parteneri, configurare operationala, suport si automatizare
- sectiunea publica trebuie sa pregateasca utilizatorul pentru catalog si conversie

## Assets to prepare

- logo final `My Darrin`
- varianta light / dark
- robot Darrin in ipostaze aprobate
- imagini relevante pentru servicii
- ilustratii pentru AI si automatizare

## Deliverables for approval

- homepage desktop
- homepage mobile
- notes pentru fiecare sectiune
- CTA map
- color usage sample

## Approval questions

- Brandingul este clar `My Darrin`?
- `Home Best Pal` apare ca slogan, nu ca produs principal?
- Darrin AI este vizibil si bine separat prin culoare si mesaj?
- Pagina invita corect catre servicii, parteneri si investitori?
- Designul poate fi transformat direct in cod fara blocaje?
