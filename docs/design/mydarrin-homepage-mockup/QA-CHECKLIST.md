# My Darrin Home Page QA Checklist

## 1. Brand validation

- Numele principal este `My Darrin`
- Sloganul `Home Best Pal` este folosit corect
- Domeniul final mentionat este `www.mydarrin.com`
- Subdomeniul temporar mentionat este `mydarrin.homebestpal.com`

## 2. Color validation

- Portocaliu principal: `#EF7F1A`
- Albastru principal: `#1E2E4D`
- Verde AI principal: `#09A299`
- Verde AI secundar: `#117A73`
- Verdele nu concureaza vizual zona principala de platforma

## 3. UX validation

- Hero-ul explica imediat ce este My Darrin
- Exista CTA principal catre servicii
- Exista CTA clar pentru parteneri
- Exista CTA clar pentru investitori
- Exista intrare clara pentru Darrin AI

## 4. Content validation

- Datele business UK sunt corecte
- Datele business Romania sunt corecte
- Email-urile oficiale sunt corecte
- Numarul de telefon UK este corect
- Numarul de telefon Romania este corect

## 5. Technical validation before implementation

- Sectiunile pot fi mapate pe componente reutilizabile
- Zona servicii poate fi alimentata din backoffice
- CTA-urile au destinatii clare in platforma
- Structura este responsive
- Nu exista elemente strict decorative care blocheaza performanta

## 6. Post-implementation validation

- CSS si JS se incarca corect
- pagina functioneaza pe mobil si desktop
- toate linkurile merg
- toate iconurile si imaginile sunt accesibile
- sectiunile dinamice au fallback corect daca datele lipsesc

## 7. Approval gate

Homepage-ul poate intra in implementare doar daca:

- brandingul este aprobat
- layout-ul este aprobat
- mesajul comercial este aprobat
- Darrin AI este aprobat ca zona distincta
- exista acord explicit pentru continuarea in productie
