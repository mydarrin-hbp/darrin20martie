# Monitoring Alerts (Cloud Monitoring)

## Alerte recomandate
1. Latenta request (p95) > 800ms (5 min)
2. Rata erori 5xx > 1% (5 min)
3. Conexiuni DB > 80% din limita

## Notite
- Se configureaza din Cloud Monitoring -> Alerting.
- Target: Cloud Run (frontend, backoffice, backend) + Cloud SQL instance.
